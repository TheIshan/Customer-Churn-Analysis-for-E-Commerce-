# Customer Churn Analysis for E-Commerce

## 📌 Project Overview
This project analyzes customer churn behavior using 100K+ order records from the Brazilian E-Commerce platform **Olist**. The goal is to identify key factors influencing customer attrition and provide data-driven recommendations to improve customer retention.

## 🛠 Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Advanced SQL (Window Functions)
- Data Visualization
- Exploratory Data Analysis (EDA)

## 📊 Dataset
The dataset contains transactional and delivery-related information of e-commerce orders, including order dates, delivery times, payment values, and customer purchase behavior.

## 🔍 Methodology
- Built an **Analytics Base Table (ABT)** using advanced SQL window functions.
- Engineered **RFM (Recency, Frequency, Monetary)** metrics to analyze customer behavior.
- Performed exploratory data analysis to study churn patterns.
- Analyzed correlation between delivery delays and customer churn.

## 📈 Key Insights
- Customers experiencing delayed deliveries showed significantly higher churn rates.
- Low-frequency and low-monetary customers were more likely to churn.
- Delivery performance strongly influenced repeat purchases.

## ✅ Recommendations
- Improve logistics and fulfillment efficiency to reduce delivery delays.
- Prioritize high-value customers with faster delivery and better service.
- Use RFM-based segmentation for targeted retention strategies.

## 🚀 Outcome
The analysis provides actionable insights that can help e-commerce platforms reduce churn and improve long-term customer retention through operational and logistics improvements.
