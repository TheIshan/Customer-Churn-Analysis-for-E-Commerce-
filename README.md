# Customer-Churn-Analysis-for-E-Commerce-
• Analyzed 100k+ order records from a Brazilian E-Commerce platform (Olist) to identify key drivers of customer
attrition.
• Engineered a comprehensive Analytics Base Table (ABT) using advanced SQL Window Functions to calculate Recency, Frequency, and Monetary (RFM) metrics.
• Conducted exploratory analysis to identify strong correlation between delivery delays and customer churn.
• Recommended logistics and fulfillment improvements to reduce churn and improve customer retention.
